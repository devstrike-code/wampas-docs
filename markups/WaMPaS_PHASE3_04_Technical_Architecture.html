01 — Phase 3 Architectural Focus

Phase 3 introduces the most architecturally significant addition: a real-time layer for fellowship rooms, prayer rooms, and direct messaging. This requires WebSocket infrastructure, a message persistence layer for room history, and read replicas for the growing database load.

05 — AI Search Architecture
1. Indexing
  • On message post: API calls OpenAI text-embedding-3-small → returns 1536-dimension vector.
  • Vector stored in messages.embedding column (pgvector).
  • Index: HNSW index on embedding column for fast approximate nearest-neighbour search.
2. Query
  • User types semantic query in search.
  • API embeds query string → cosine similarity search against messages.embedding.
  • Results ranked by similarity score + recency + reaction count.
  • Returns top 20 semantically relevant messages regardless of exact keyword match.
