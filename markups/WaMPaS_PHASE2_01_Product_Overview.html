01 — Phase 2 Objective

Phase 2 monetises the audience built in Phase 1, completes the Events layer, and seeds the Social layer. The platform begins earning revenue from church event advertising while introducing the public feed that gives users a daily reason to return.

Phase 2 Entry Gate

Phase 2 begins only when Phase 1 metrics are met: 1,000+ messages, 500+ users, confirmed WhatsApp referral loop. Rushing Phase 2 before Phase 1 is proven wastes the monetisation window.

02 — New Capabilities Unlocked

Events Layer (Full)

  • Sponsored upcoming event listings — churches pay to promote crusades and conferences
  • Google Calendar integration — account users save events with one tap
  • Event-linked fellowship rooms — community space attached to a specific event
  • Push notification event reminders via FCM
  • Event ad subscription payment via Paystack

Archive Enhancements

  • Verified pastor and church profiles (blue check, annual fee)
  • Denomination branch awareness — HQ can view message volumes by branch
  • Feature suggestion system — users propose and vote on features
  • Donation flow — voluntary user contributions to platform development
  • PWA installability — add to home screen, offline read cache

Social Layer — Seed

  • Public feed — users post reflections, share archive messages, post scripture
  • Pastor following — follow a pastor's archive and feed activity
  • Social reactions — Amen, Fire, Praying (no secular thumbs-up)
  • Threaded post comments with moderation
  • Public prayer requests on the feed
