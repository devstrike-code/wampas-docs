01 — Phase 1 Architecture Principle

Phase 1 architecture is intentionally minimal. One Next.js app on Vercel, one Node.js API on Railway, one PostgreSQL database. No cache layer, no job queue, no WebSockets. All of these can be added later — starting without them keeps Phase 1 fast to build and easy to debug.

04 — Quote Card Generation
