01 — Phase 3 Infrastructure Focus

Phase 3 introduces the most significant infrastructure addition: a real-time WebSocket layer for fellowship rooms, prayer rooms, and DMs. A read replica is added to handle the read-heavy browse load. AI embedding generation is added for semantic search.

02 — New Phase 3 Components
WebSocket Server Ably (managed) or Soketi (self-hosted on Railway)
Tier: Ably: usage-based | Soketi: ~$10/month
Estimated Cost: ₦32,000–₦64,000/month
Powers real-time messaging in fellowship rooms, live prayer sessions, and DMs. Ably recommended for Phase 3 launch — managed service, Nigerian PoPs, no DevOps overhead. Evaluate Soketi at Phase 3 maturity for cost optimisation.
Scaling trigger: Ably free tier: 200 concurrent connections, 6M messages/month. Upgrade when: concurrent connections regularly > 160 (80% of limit).
Database Read Replica Railway PostgreSQL replica
Tier: ~$15–20/month
Estimated Cost: ₦24,000–₦32,000/month
All read-only API queries (GET endpoints) routed to replica. Write queries continue to primary. Dramatically improves browse-heavy load performance as archive grows to 250,000+ messages.
Scaling trigger: Add replica when: read:write ratio > 10:1, or GET query P95 consistently > 100ms.
AI Embedding Service OpenAI text-embedding-3-small API
Tier: Usage-based (~$0.02/1M tokens)
Estimated Cost: ₦32,000–₦64,000/month
Generates 1536-dimension vector embeddings for every new message post. Stored in pgvector column. Powers semantic search — 'find everything said about healing by Yoruba pastors'. Cost is negligible per message (~₦0.05 per embedding).
Scaling trigger: Cost scales linearly with message volume. At 250,000 messages: total embedding cost ~₦2,500 one-time. Monthly cost is ongoing for new posts only.
Upstash Redis (paid) Upstash Redis Pay-per-use
Tier: Usage-based
Estimated Cost: ₦16,000–₦32,000/month
Now critical for: WebSocket presence caching, live prayer room session state, feed personalisation cache, premium subscription status cache. Free tier was sufficient for Phase 2 — Phase 3 social features push beyond it.
Scaling trigger: Upgrade from free tier when daily Redis commands consistently > 8,000.
